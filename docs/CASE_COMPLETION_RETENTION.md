# Case completion and retention

The current workflow is field submission → saved report → valuator completion. Senior approval and reviewer assignment are no longer required in the website. Historical review status values and reviewer IDs are preserved so existing records remain compatible. Valuators can complete legacy review cases or return them to field data/report editing. Completed cases remain read-only.

Completion time is generated by the database. Signed-in users cannot set or backdate it. At least one saved report is required before completion; editing a drafted dossier invalidates its draft status as before.

## Permanent deletion

The new Supabase project `gwqfwtcxlwcmglrozshc` runs `hem-completed-case-retention` hourly. Eligibility is `status = completed` and `completed_at <= now() - interval '30 days'`. Missing completion dates never qualify. The job invokes no Edge Function when no cases qualify. Each worker invocation handles at most ten cases and up to 100 Storage objects per case; larger cases continue on the next run.

The service-only inventory finds files in photos, documents and reports by case prefix and linked paths, including original photos and uploads without metadata. A file referenced by another case is retained for that case. Deletion uses the Storage API to remove actual payloads. Only after Storage inventory is empty does a locked, timestamp-checked database RPC delete the case. Foreign keys cascade to photos, documents, reports, field data, location, extracted data, events and assignment notifications/deliveries. Failed or incomplete file removal preserves case records for retry.

The Edge endpoint requires the encrypted shared webhook secret. Public and authenticated clients cannot execute the inventory/finalize RPCs. No customer content, file paths or secrets are logged by the worker. Notification dispatcher Vault credentials are reused on the server; no extra client credentials or paid service are introduced.

To stop automatic cleanup, unschedule `hem-completed-case-retention` in Supabase Cron. Deleted cases/files cannot be restored through the app. Any independent exports or backups have their own retention; this job does not erase downloaded reports or local migration backups.
